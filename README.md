# Die Grenzen von cachebasierten Covert-Channels im Kontext von Transient-Execution: ein technischer Überblick
Das Repository enthält den LaTeX-Sourcecode meiner Bachelorarbeit und der Präsentation. Außerdem ist jeweils ein kompiliertes PDF vorhanden.

Personenbezogene Daten wurden bewusst aus den Dateien entfernt, um nur den Inhalt zur Verfügung zu stellen.

Die Arbeit beschäftigt sich mit der Optimierung von chachebasierten Covert-Channels bei Angriffen mit Transient-Execution, bei denen die ausgeführten Instruktionen während der Transient-Execution von dem Angreifer kontrolliert werden. Betrachtet werden dabei die Encodierung des Secrets in den Cache-Zustand sowie das Auslesen dieses Zustands. Anhand verschiedener messbarer Parameter wird der Durchsatz des Covert-Channels, abhängig von der Encodierung, modelliert und optimiert. Der ermittelte maximale Durchsatz stellt eine theoretische Grenze für den Durchsatz eines Angriffs mit Transient Execution, in einem gegebenen System, unter Verwendung eines bestimmten cachebasierten Covert-Channels, dar.
